# Data
This repository does not contain the dataset.

Download the **UCI Condition Monitoring of Hydraulic Systems** dataset
(Helwig, Pignanelli & Schütze, 2015, DOI 10.24432/C5CW21, licence CC BY 4.0):
https://archive.ics.uci.edu/dataset/447/condition+monitoring+of+hydraulic+systems

Unzip the files (`PS1.txt` … `PS6.txt`, `EPS1.txt`, `FS1.txt`, `FS2.txt`, `TS1.txt` … `TS4.txt`,
`VS1.txt`, `CE.txt`, `CP.txt`, `SE.txt`, `profile.txt`) into `data/raw/`.
